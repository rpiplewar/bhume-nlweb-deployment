🤖 NLWeb MCP Server Documentation

🔗 Quick Claude Desktop Setup

To use this MCP server with Claude Desktop, add this configuration:

{
  "mcpServers": {
    "nlweb": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-sse",
        "http://localhost:8000/mcp/sse"
      ]
    }
  }
}

Replace the URL with your actual server URL if different.

📋 Available Endpoints

GET/mcp

Server discovery endpoint. Returns server information, capabilities, and examples.

POST/mcp

Main MCP endpoint. Accepts both JSON-RPC 2.0 and legacy function_call formats.

GET/mcp/sse

Server-Sent Events endpoint for streaming MCP connections.

POST/mcp/sse

SSE-based MCP requests with streaming responses.

GET/mcp/health

Health check endpoint.

GET/mcp/capabilities

Detailed server capabilities information.

🛠️ Available Tools

ask_nlw

Primary search tool. Search and retrieve information from NLWeb data sources.

Parameters:

  • query (required): Natural language search query
  • site (optional): Specific site to search, or 'all' for all sites
  • prev_query (optional): Previous query for context
  • context_url (optional): URL for additional context
  • streaming (optional): Enable streaming response

get_sites

Get list of available sites/data sources that can be searched.

Parameters: None

📖 Protocol Documentation

JSON-RPC 2.0 Format

Standard MCP requests use JSON-RPC 2.0 format:

{
  "jsonrpc": "2.0",
  "method": "tools/call",
  "params": {
    "name": "tool_name",
    "arguments": { ... }
  },
  "id": 1
}

Legacy Function Call Format

For backward compatibility, the legacy format is still supported:

{
  "function_call": {
    "name": "tool_name",
    "arguments": "{\"param\": \"value\"}"
  }
}

Response Format

Successful responses return:

{
  "jsonrpc": "2.0",
  "result": { ... },
  "id": 1
}

Error responses return:

{
  "jsonrpc": "2.0",
  "error": {
    "code": -32000,
    "message": "Error description"
  },
  "id": 1
}
